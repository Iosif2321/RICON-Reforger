# Карта исходного кода RICON

```text
Device ──► Core ──► Propagation
             │           │
             └──► Network ◄──┘
```

Схема показывает основные связи по смыслу, а не полный граф вызовов.

| Каталог | Назначение |
|---|---|
| [Core](Core/README.md) | Управление, состояние устройств и связей, временные данные и публикация. |
| [Device](Device/README.md) | Адаптеры и наблюдения радиоустройств, проекция пар и геометрия. |
| [Propagation](Propagation/README.md) | Модели пути сигнала, потерь, шума и характеристик среды. |
| [Network](Network/README.md) | Контракты сети, экспериментальные медиамаршруты, приём и ретрансляция. |

Серверные права, жизненный цикл и время участвуют в решениях о маршрутах. Реальный голосовой тракт и игровая приёмка пока остаются открытой работой.
