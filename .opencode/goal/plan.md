Текущий переход — запись утверждённого intent и самодостаточная передача в свежий контекст проектирования. Для нового назначенного пользователем участника отдельно сохраняется проверка свежести: отсутствие прежнего контекста им подтверждено, точное время создания сессии независимо не установлено. При непрохождении этого gate — FRESH_SESSION_REQUIRED, не молчаливое исключение.

Следующий результат — DRAFT технической спецификации минимального опровергающего probe для AI-event VoN либо обоснованной альтернативы. Реализация, новая бинарная RE, GUI-мутации, снятие production-блокировки и публикация этим переходом не разрешаются.
