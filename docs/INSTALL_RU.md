# Установка RICON Core 0.6.3 на Windows

## Локальная альфа со штатным VoN

Закройте игру. Скачайте игровой ZIP, извлеките папку `RICON_Core` в `Документы\My Games\ArmaReforger\addons` и добавьте `-addons 7C060DB9E8B90AC7` в параметры запуска Steam. Перед заменой старой копии сохраните её отдельно. Для сетевого матча серверу и игрокам нужен одинаковый аддон.

Запустите **Сценарии → RICON Radio Training**. Основной открытый канал — 38 МГц. **Caps Lock** включает передачу по выбранной рации, **T** включает ближний голос. Если игра молчит, проверьте громкость Arma Reforger в микшере Windows.

На выделенном сервере объекты РЭБ и ретрансляторы настраиваются через Game Master. [Настройки](GM_RF_INFRASTRUCTURE_RU.md)

## Игровой мод

1. Закройте Reforger. Откройте системную папку «Документы», затем `My Games\ArmaReforger\addons`. Если каталога `addons` пока нет, создайте его.
2. Распакуйте в `addons` папку `RICON_Core` из [игрового ZIP 0.6.3](https://github.com/Iosif2321/RICON-Reforger/releases/download/0.6.3/RICON-Core-0.6.3.zip). Проверьте путь `addons\RICON_Core\addon.gproj`. Достаточно одного уровня `RICON_Core`. Вместо ручной распаковки в этом checkout можно запустить [локальный установщик](../tools/install-local-addon.ps1) с параметром `-Archive` и путём к игровому ZIP. Он сверяет SHA-256 и сохраняет уже существующую отличающуюся копию.
3. В Steam откройте **Библиотека → Arma Reforger → Свойства → Общие → Параметры запуска**. Введите `-addons 7C060DB9E8B90AC7`. Если параметр `-addons` уже содержит другие GUID, добавьте `,7C060DB9E8B90AC7` к существующему списку.
4. Нажмите **Играть**. В главном меню появляется панель с версией RICON. Для прямого старта тренировочной карты добавьте `-world worlds/RICON/RICON_MixedRadioDemo.ent`. Для обычного главного меню уберите `-world` и его значение. Сетевая радиосвязь проверяется на dedicated-сервере с этим модом.

При пользовательском `-profile` игровой каталог аддонов — `addons` рядом с внутренней папкой `profile`. Эта локальная сборка активируется штатным параметром игры. Публикация в Bohemia Workshop для неё не выполнялась. [Параметры запуска Reforger](https://community.bistudio.com/wiki/Arma_Reforger%3AStartup_Parameters).

## Плагин TeamSpeak

1. Закройте TeamSpeak 3.6.2 x64 и откройте [публичный RICON.ts3_plugin 0.6.3](https://github.com/Iosif2321/RICON-Reforger/releases/download/0.6.3/RICON.ts3_plugin). Подтвердите установку штатным TeamSpeak Package Installer. При отсутствии ассоциации откройте файл через `package_inst.exe` из папки TeamSpeak.
2. Запустите TeamSpeak и Reforger. При совпадении версий панель показывает «Плагин TeamSpeak 0.6.3 отвечает». При необходимости включите плагин в **Инструменты → Параметры → Аддоны → Подключаемые модули**.
3. Публичная сборка использует HTTPS-каталог чистого репозитория. Предыдущие стендовые сборки с адресом приватного DEV, в том числе 0.6.2 и локальная 0.6.3, требуют однократной ручной установки публичного пакета. Версия уже установленной DLL сама по себе не различает каналы. Штатное самообновление проверяет подпись, готовит новую версию и применяет её после выхода TS3.

Архив **Source code**, автоматически созданный GitHub для тега, не является проверенным игровым ZIP. [Публичный релиз](https://github.com/Iosif2321/RICON-Reforger/releases/tag/0.6.3) · [Релиз DEV](https://github.com/Iosif2321/RICON-Reforger-DEV/releases/tag/0.6.3).
