Реализован отдельный вычислитель `oracle/material_profile_oracle.py` по
`docs/req/REQ-material-profile.md` v0.2 FROZEN. Он принимает явный профиль и частоту и выдаёт материал для
существующего P3.2a slab с границами ровно на этой частоте. Никакого распознавания игрового объекта или
автоматического выбора параметров по названию материала нет.

Каталог содержит 38 строк Table 3 ITU-R P.2040-4. Формулы (57)–(58), числа и полосы самостоятельно проверены
по изображениям PDF-страниц 27–28 (печатные 25–26), отрисованным штатным WinRT из официального PDF.
SHA-256 PDF: `f2b73e144129f52ff2c0bf2789dcf86f573035caffbc8e1549e691c9cfc023e3`.
Особо проверены металл σ=10^7, wood от 0.001 ГГц, 0.1 ГГц для первого стекла и исключённые верхние границы
трёх частей floorboard. Повторяющиеся классы сохранены отдельными ID; вне полосы — явный отказ.

Проверки автора:

```text
python -B -X utf8 oracle/build_material_profile_vectors.py --check
python -B -X utf8 oracle/material_profile_oracle.py --check oracle/vectors/material_profile_v1.json
python -B -X utf8 -m unittest discover -s oracle -p test_material_profile_oracle.py
```

236 случаев rev2: 223 доступны в native, 13 относятся к JSON-границе. Десять тестов проверяют независимую прямую
степенную формулу (380 точек), границы/разрывы, no-write для `--check`, неверные типы/числа, повреждения каталога,
SHA корпуса, неизменность входа и результата, отсутствие ложной нулевой проводимости при underflow.
Дополнительная регрессия включает четыре численных края: округление 9e-46 к минимальному положительному
binary32, потерю точности промежуточной степени, конечную проводимость выше допустимой области и ε чуть ниже 1.
Последний случай предотвращает ошибочное признание материала допустимым при чрезмерном масштабировании степени.
Три вызова существующего slab с профилями wood/concrete/metal проверяют передачу параметров, происхождение и
отказ при попытке повторно использовать одночастотный материал на другой частоте.

На 20–76 МГц из этих примеров применимы лишь воздух и первый wood. Бетон/кирпич/металл на УКВ,
конкретные материалы карты, влажность/армирование и геометрия стен остаются отдельной задачей.
SOURCE_DOMAIN характеризует происхождение параметров в полосе, а не измеренную достоверность объекта игры.
