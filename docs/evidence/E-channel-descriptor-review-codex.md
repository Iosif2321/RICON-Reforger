## Ревью исходников

Codex прочитал весь `RICON_ChannelDescriptor.c`, изменение `RICON_ChannelFading.c`, fixture support,
генератор и сверил с CD02–CD08. Блокирующих расхождений в кодеке нет:

- структура CF проверяется до использования; лимит Decode — до обхода элементов, далее bounded frame/key/count;
- знаковый int32 собирается без переполнения: старший байт со знаком, дальнейшие положительные слагаемые
  не выводят промежуточную сумму за int32; запись соответствует big-endian;
- преобразование конечного binary32 использует точные степени 2; все промежуточные величины остаются
  представимыми. Для субнормали мантисса сохраняется целой при конечном масштабе 2^-149;
- Inf/NaN отвергаются; знак проходит до CF/каноничности, нулевой вес нормализуется к +0;
- Decode повторно упаковывает новый descriptor и сравнивает весь кадр; нет принятия усечённого/лишнего хвоста;
- Rebase сохраняет срок и коэффициенты, использует принятую модульную арифметику CF06 без float-времени;
- ошибки возвращают только код; успешные результаты глубоко отделены от входов; origin не выдаётся за
  доказательство авторитетного отправителя.

Найдена одна дыра тестового сравнения: у OK Rebase ветвь без массива байтов игнорировала sizeBytes.
По Agora #3662 Claude добавил норму size=0 и контрольную порчу size=99999 (`c1ee53c`), production-код не менялся.
Проверка fixture `--check` и **5/5** unit-тестов генератора пройдены независимо.
