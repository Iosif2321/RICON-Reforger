# Заказ `[Workbench]` №002 — компиляция `RICON_Core`

Дата: 2026-10-18. Заказчики: claude + codex (тема agora `ricon-reforger-build`, спринт 6).
Исполнитель: ассистент владельца в Workbench (Arma Reforger Tools). Результат — в
`docs/evidence/E-workbench-source.md`, раздел «Компиляция №002».

Заказ дополняет пункт 10 заказа №001 (`WB-order-001.md`). Если №001 ещё не выполнен, пункт 10 можно заменить
этим заказом: он описывает точнее, что компилировать и что прислать.

## Правила

- Только проверка компиляции скриптов. **Без Play-режима, без сервера, без запуска мира.** Распаковщики `.pak` и
  сторонние инструменты не используются (обратная разработка запрещена).
- Компилировать ровно указанную ревизию репозитория. Код не исправлять — только сообщить результат.
- Агенты эту проверку сами не запускают (решение владельца №3).

## Что компилировать

- Репозиторий: `C:\Users\Ded\Documents\Projects\ARMA 3 Scripts\RICON-Reforger`.
- Ревизия: **последний коммит после закрытия спринта 6** — агенты укажут хэш в шине вместе с этим заказом.
  Перед проверкой: `git -C "<репозиторий>" log --oneline -1` и `git -C "<репозиторий>" status --short` (должен
  быть пуст). Оба вывода — в отчёт.
- Проект: `addons\RICON_Core\addon.gproj`.

## Как (по документации Tools, `E-workbench-build.md`)

Предпочтительно — без окна:

```bat
"C:\Program Files (x86)\Steam\steamapps\common\Arma Reforger Tools\Workbench\ArmaReforgerWorkbenchSteamDiag.exe" ^
  -gproj "C:\Users\Ded\Documents\Projects\ARMA 3 Scripts\RICON-Reforger\addons\RICON_Core\addon.gproj" ^
  -wbModule=ScriptEditor -validate -wbSilent -noThrow ^
  -logLevel warning -logsDir ricon-validate-002 -log-scr-checksum
echo exit=%ERRORLEVEL%
```

Если команда не работает так, как описано в документации (например, нужен `-run`, не находится базовая игра
или нет кода возврата), — допустимо открыть проект в Workbench и выполнить компиляцию из Script Editor.
В отчёте указать, какой способ сработал и что пришлось изменить в команде.

## Что прислать

1. Версия игры и Workbench (Help → About), дата.
2. Ревизия и `git status` (см. выше).
3. Точная команда или путь в меню, которым запускалась компиляция.
4. Код возврата (для CLI).
5. **Полный текст всех ошибок и предупреждений** компиляции скриптов с файлами и строками — дословно.
6. Из лога `-log-scr-checksum` — список файлов `Scripts/Game/RICON/**`, попавших в компиляцию (подтверждает,
   что компилировался именно наш код).
7. Путь к папке логов, если её можно приложить.

## Как агенты используют результат

- Код возврата `0`, в логе нет ошибок и файлы RICON в списке checksum → статус `WORKBENCH_COMPILE_PASS` для
  этой ревизии (только компиляция; поведение и runtime остаются непроверенными).
- Любая ошибка → агенты исправляют код в следующем спринте и выпускают заказ №003 на ту же проверку.
