## Первичная страница

[ITU, Recommendation P.372-18](https://www.itu.int/rec/R-REC-P.372-18-202609-I/en) прочитана web-инструментом
в этой сессии, 2026-10-21. Метаданные:

- одобрена 2026-09-08, статус In force (Main);
- Access: Free Download;
- английский PDF: 30 437 927 байт, опубликован 2026-09-25.

Уровень — STD_PAGE для этих полей. PDF SHA неизвестен: локального полного файла не получено.
Копия официальной страницы в архиве и её SHA отдельно сохранены claude в `E-web4-propagation-measurements.md`.
Проверка существования -18 не подтверждает её технические формулы.

Точный первичный PDF:
`https://www.itu.int/dms_pubrec/itu-r/rec/p/R-REC-P.372-18-202609-I!!PDF-E.pdf`.

## Что действительно проверено

| Путь | Фактический результат | Что этим не доказано |
|---|---|---|
| web open первичного PDF | ошибка `(400) Content length is too large: 30437927` | файл не отсутствует; его содержание не прочитано |
| CUA.getBrowser по URL | `No browser is available` | это не ошибка TLS или формата PDF |
| CUA.getState | `apps:[], browsers:[]` | нет подключённой поверхности в этой сессии, не «браузеров вообще нет» |
| CUA.createBrowserTab(iab, PDF, visible:false) | `Browser is not available: iab` | не проверен просмотр PDF в другом реально подключённом браузере |
| Windows curl8.13.0 / Schannel, обычная проверка TLS | exit35: `schannel: failed to receive handshake, SSL/TLS connection failed` | не отказ в праве загрузки и не HTTP404 |
| Acrobat pdf_to_markdown с assets=[публичный HTTPS URL], include_figures=true | ошибка до сервиса: URL трактуется upload-адаптером как локальный Windows-путь, os123 | не доказана невозможность Acrobat обработать корректно переданный asset |

CLI-попытка curl использовала уникальный путь во временной папке, таймаут45с и flags --fail --location.
Полного файла не создано. Сертификаты/настройки TLS не отключались, браузеры/расширения/зависимости не ставились.
Другие активные окна и профили пользователя не управлялись.

Воспроизведение HTTP-попытки (место результата выбирается явно):

```powershell
& 'C:\Windows\System32\curl.exe' --fail --location --max-time 45 --output '<временный путь>\p372-18.pdf' 'https://www.itu.int/dms_pubrec/itu-r/rec/p/R-REC-P.372-18-202609-I!!PDF-E.pdf'
```

Для повторения CUA требуется реально подключённый браузер. До появления такого подключения повторять
навигацию бессмысленно; условия и ответ интерфейса зафиксированы выше, а не превращены в вывод о PDF.

## Разрешения и следующий проверяемый шаг

Правила доступного codex Computer Use прямо относят inbound downloads к категории без подтверждения.
Нового обязательного owner-gate для публичного PDF не вводим. Предел здесь технический, не разрешительный.
У партнёра может быть другой инструмент со своими правилами; его сеанс/профиль автоматически не присваивается.

Следующие варианты: подключённый браузер с PDF-viewer; получение корректного публичного asset поддерживаемым
коннектором; файл, доступный владельцу. Ни один из них не объявлен единственным. Это не предложение обходить
TLS-предупреждения, paywall или безопасность браузера.

После получения полных байтов: проверить `%PDF`, размер/SHA; независимо извлечь текст штатным
`C:/Program Files/Git/mingw64/bin/pdftotext.exe`; визуально сверить ур.(17), Table1, график/формальную область
с -17. До такого чтения содержание -18 и необходимость изменений формул/домена остаются OPEN.
