# Заказ `[Workbench]` №001 — ванильные файлы Arma Reforger

Дата: 2026-10-18. Заказчики: claude + codex (тема agora `ricon-reforger-build`, спринт 1).
Исполнитель: ассистент владельца в Workbench (Arma Reforger Tools). Результат — в
`docs/evidence/E-workbench-source.md`.

## Правила сессии

- Только Workbench: Resource Browser, Script Editor, Audio Editor, Prefab/Config viewer. **Без Play-режима
  и без сервера.** Никаких распаковщиков `.pak` и сторонних инструментов (обратная разработка запрещена).
- Ванильный код и ассеты **не копировать** в репозиторий целиком. В отчёт — путь ресурса, версия игры и
  короткие цитаты (до ~15 строк на пункт), необходимые для ответа; остальное — пересказ своими словами.
- Для каждого пункта: путь ресурса в Workbench, номера строк (для скриптов), что найдено, что не найдено.
- В начале отчёта: версия игры и Workbench (Help → About), дата.
- Уровень каждого вывода — `SOURCE_EVIDENCE`: структура, атрибуты, код. Поведение (доставка голоса,
  слышимость, работа ретранслятора, per-pair DSP) статически не доказывается и остаётся
  `BLOCKED_NO_RUNTIME` до Э1r. SOURCE фиксирует только видимую структуру и логику: если пересылка
  голоса, per-pair или звуковое поведение не следуют прямо из исходника/графа, ответ — `НЕ УСТАНОВЛЕНО`,
  без вывода о runtime.
