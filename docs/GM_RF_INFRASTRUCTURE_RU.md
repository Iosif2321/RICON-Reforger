# Инфраструктура RICON в Game Master

Модули рассчитаны на сценарий, в котором доступен Game Master и включён игровой RF-менеджер RICON. Для стандартного сценария без этого менеджера потребуется добавить его при сборке сценария. Роли доступны через штатное окно свойств GM.

## Зона РЭБ или РЭБ на объекте

1. В каталоге GM выбери **RICON Jammer Zone — RC-292** для антенны, **RICON EW - Fixed Station Building** для стационарного здания или **RICON EW - Ural Command Vehicle** для подвижной РЭБ. Роль также можно назначить существующему редактируемому зданию, антенне или машине. Шум исходит из текущей позиции выбранного объекта.
2. Открой свойства объекта и настрой поля **RICON EW**. Они относятся только к выбранному экземпляру.
3. Выставь **Enabled** в 1. Выставь 0, чтобы отключить помеху и сохранить настройки на текущий матч. При удалении объекта его излучение прекращается.

| Поле | Значение |
|---|---|
| **Centre (MHz)** | Центральная частота игровой полосы помехи. |
| **Width (kHz)** | Полная ширина полосы вокруг центра. |
| **Power (dBm)** | Суммарная мощность игрового шума во всей полосе. |
| **Antenna gain (dBi)** | Усиление виртуальной передающей антенны. |
| **Zone radius (m)** | Граница учёта источника. У готовых платформ РЭБ исходное значение 500 м. Значение 0 оставляет расчёт только по распространению без границы зоны. |

Расчёт идёт по каждому игровому приёмнику. Учитываются положение, пересечение полос и суммарная мощность от включённых источников. Внутри радиуса сильный полезный сигнал может остаться доступным. Для нескольких раздельных полос можно разместить несколько источников. Каждый экземпляр поддерживает одну сплошную полосу.

На выделенном сервере с игровым менеджером RICON и штатным VoN сильная помеха подавляет конкретный радиослот. Менеджер сравнивает помеху на приёмнике с потенциальными сигналами зарегистрированных передатчиков на той же частоте и с тем же ключом. Слот блокируется, когда помеха сильнее каждого подходящего передатчика. RICON снимает свою блокировку при изменении условий, отключении или удалении объекта. Соседний слот, интерком и DIRECT используют свои штатные пути.

## Ретрансляторы

GM выбирает инфраструктурный объект в каталоге:

- **RICON Relay - R-142 Antenna Mast** — стационарная антенная мачта.
- **RICON Relay - Communications Building** — здание узла связи.
- **RICON Relay - Field Radio Station** — полевая радиостанция как готовый объект на местности.
- **RICON Relay - Ural Command Vehicle** — командная машина.

На каждой платформе установлен штатный трансивер-ретранслятор. В свойствах экземпляра **Enabled** включает роль, **Input (MHz)** выбирает общую частоту обоих плеч, а **Stock range (m)** задаёт дальность второго плеча. Первое плечо ограничено штатной дальностью исходной рации. Используйте один совместимый ключ у раций и станции. Готовые объекты настроены на открытый канал. При выключении, удалении или отзыве роли ретранслятор прекращает обслуживать эту частоту.

Два обычных слота остаются доступны для сценарных маршрутов RICON. Поля **Output (MHz)** и **Power (dBm)** предназначены для этих маршрутов. Штатный VoN повторяет канал без преобразования частоты. Инвентарные рации сохраняют роль абонентов. Их параметры редактируются в [серверном конфиге](RADIO_HARDWARE_RU.md).
