## 1. Назначение и границы

**VG01.** Слой оценивает дополнительные потери растительности на **заданной прямой TX→RX**, описанной
VEGETATION-сегментами P2. Геометрию пути он не меняет. Мир, трассы и распознавание деревьев не исполняются.

**VG02. Ансамбль.** Для каждого сценария (§3) задан закрытый список применимых моделей с объявленной областью и
**основная** модель по закрытому приоритету. Все применимые модели считаются в эталоне и в native-проверке; при
исполнении в игре профиль может ограничить вычисление основной моделью и кэшировать сверку по сцене и частоте
(#3485). Разброс кандидатов (min/max) — диагностика расхождения моделей, **не** доверительный интервал и не строгая
граница для P1. Модели одной потери не усредняются и не суммируются. Сценарий без единой применимой модели —
`NO_MODEL_FOR_SCENARIO`, а не 0 и не LOST.

## 2. Модели

**VG03. M1 — P.833-10 ур. (1), конец внутри леса.** Aev = Am·[1 − exp(−d·γ/Am)]: d — длина пути в лесу (м),
γ — погонное затухание (дБ/м), Am — наибольшее дополнительное затухание (дБ), Am = A1·f^α (ур. 2, f в МГц).
γ и (A1, α) берутся из записи каталога (VG07). Область — диапазоны записи каталога.

**VG04. M2 — P.833-10 ур. (7), одиночное препятствие.** Aet = d·γ при f ≤ 1000 МГц, оба конца вне растительности.
Стандарт ограничивает Aet потерями обходного пути (тонкий экран по P.526) и предупреждает, что без этого ур. (7)
завышает потери.

**VG05. M3 — MED, DoD ECAC (основная военная модель).** Погонное затухание α = 1.33·F^0.284·d^−0.412 дБ/м при
14 ≤ d ≤ 400 м и α = 0.45·F^0.284 дБ/м при 0 ≤ d < 14 м (ECAC ур. 6a/6b, F в ГГц), откуда
L = 1.33·F^0.284·d^0.588 и L = 0.45·F^0.284·d (ур. 36a/36b). Область: 230 МГц ≤ f ≤ 95 ГГц, 0 < d ≤ 400 м;
по ECAC — луч перекрыт плотным сухим лесом в листве умеренных широт, одна или обе антенны близко к роще.

**VG06. M4 — Jansky & Bailey (ECAC §5), обе антенны в лесу.**
Lb = 36.57 + 20·lg f − 20·lg[A·e^(−1609·α·d)/d + B/d²] (ур. 11), Lb — базовая потеря передачи (дБ), f в МГц, d в
статутных милях (1 mi = 1609.344 м), α, A, B — табл. 13 для поляризации V или H. Дополнительная потеря
растительности: Aj = Lb − (36.57 + 20·lg f + 20·lg d) — вычитается потеря свободного пространства той же
дистанции в тех же единицах. Область: 25 ≤ f ≤ 400 МГц, 8 ≤ d ≤ 1600 м, высоты обеих антенн над землёй 2…7 м.
Модель построена по тропическому лесу (Пак Чонг, Таиланд); ECAC сообщает rms-ошибку 5–14 дБ.
Между частотами табл. 13 (25, 50, 100, 250, 400 МГц) α, A, B интерполируются линейно по lg f — это
`ASSUMED`-конвенция RICON, в стандарте не задана; на частотах таблицы значения точные.
На коротких путях в H-поляризации (около 75–150 МГц, d ≈ 8–12 м) Aj получается отрицательным — это артефакт
подгонки (растительность не усиливает сигнал); такой кандидат M4 исключается как неприменимый.

**VG07. EXD (ECAC ур. 35), только диагностика.** L = 0.26·F^0.77·d (F в ГГц). ECAC показал rms-ошибки EXD до 37 дБ;
в ансамбль кандидатов не входит, выдаётся отдельным полем для сравнения.

**VG08. Каталог растительности** `catalog`: `materialId → VegetationProfile`, `ASSUMED_CONFIG` (значения задаёт
владелец или калибровка; в корпусе TEST_ONLY).

| Поле | Домен и смысл |
|---|---|
| negligible | bool; трава и мелкие кусты (#3311), потерь не дают; задаётся по проверенным данным, не порогом размера |
| climate | `TEMPERATE` или `TROPICAL`; M3 применима только к TEMPERATE, M4 — только к TROPICAL |
| gammaTable | 2–32 точки `[fMHz, γ]`, f строго возрастают, γ > 0; интерполяция по (lg f, lg γ), без экстраполяции |
| amA1, amAlpha, amMinMHz, amMaxMHz | Am = amA1·f^amAlpha в [amMinMHz, amMaxMHz] |

При negligible = true остальные поля отсутствуют. Числа — по PO03 P2.

**VG09. Дополнительный вход P4** (не часть P2): `polarization` — `V` или `H`; `txHeightM`, `rxHeightM` — высота
антенны над землёй (м) или null. Без обеих высот M4 неприменима.

## 3. Карта сценариев

**VG10.** Сегменты VEGETATION обрабатываются как в P2: UNKNOWN и HINT_ONLY или materialId вне каталога →
`VEGETATION_UNKNOWN`; negligible отбрасываются; остальные интервалы объединяются; объединённый интервал с несколькими
materialId → `VEGETATION_MIXED_PROFILE`. Для каждого объединённого интервала длины d:

| Сценарий | Условие | Кандидаты (в порядке приоритета) | Если ни один не в области |
|---|---|---|---|
| S1 | касается ровно одного конца | M3, M1 (основная — первая применимая) | NO_MODEL_FOR_SCENARIO |
| S2 | касается обоих концов ([0, L]) | M4, M3 | NO_MODEL_FOR_SCENARIO |
| S3 | посреди пути, d ≤ 400 м | M3, M2; `capApplied = false` | NO_MODEL_FOR_SCENARIO |
| S3+ | посреди пути, d > 400 м | — (нужен путь над кронами, открыто) | NO_MODEL_FOR_SCENARIO |

Применимость — по области модели (частота, d, климат записи, поляризация и высоты для M4, наличие таблиц для M1/M2).
Основная оценка интервала — первая применимая модель списка; кандидаты — все применимые с их потерями; spread —
min/max кандидатов. Итог слоя — сумма основных оценок интервалов.

**VG11. Открытые сценарии (следующий срез «геометрия кандидатов»).** Путь над кронами: ECAC §2.6.2/§3.6 предписывает
считать и потери сквозь лес, и дифракцию поверх (knife-edge с эффективной высотой ниже верхушек), и брать меньшую;
по углу от ближней антенны к верхушкам: 26–90° — только сквозь (MED), 8–26° — обе, 0–8° — только поверх. P.833 ур. (7)
требует того же ограничения. Для этого нужны высоты крон и путь над ними — L2 P.526 по профилю крон; до этого среза
`capApplied = false`. Модель Kinase (антенна высоко над растительностью, 80–700 МГц) задана в ECAC только графиками;
COST 235 и FITU-R (мм-диапазон) — без первоисточника; латеральная волна Tamir — для сверки дальних путей M4.

## 4. Результат

**VG12.** Порядок причин: `INVALID_OBSERVATION` → `INVALID_INPUT` (каталог, polarization, высоты) →
`VEGETATION_COVERAGE_INCOMPLETE` → `VEGETATION_UNKNOWN` → `NO_VEGETATION` (слой 0 дБ, вычислено) →
`VEGETATION_MIXED_PROFILE` → `NO_MODEL_FOR_SCENARIO` → `NUMERIC_FAILURE` → `OK`. При OK по каждому интервалу:
startM, endM, materialId, сценарий, основная модель и её потери, список кандидатов {model, lossDb}, spreadMin/Max,
EXD для сравнения, capApplied. Слой никогда не объявляет LOST и не выдаёт строгих границ для P1.

`oracle/vectors/vegetation_v1.json`, сборщик `oracle/build_vegetation_vectors.py`. Unit-тесты: непрерывность MED на
