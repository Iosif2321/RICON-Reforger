# Параметры раций RICON

RICON Radio Training использует опытные профили для карманной AN/PRC-68, рюкзачной AN/PRC-77 и станции УАЗ. Совместимые слоты рассчитаны на открытый канал 38 МГц с полосой приёмника 25 кГц. В машине станция доступна водителю. Штатный интерком обрабатывается отдельно.

Скопируйте [пример с пояснениями полей](examples/ricon-radio-hardware.json) под именем `ricon-radio-hardware.json` в `$profile:` хоста или dedicated-сервера. Для запуска с `-profile C:\ServerProfile` фактический путь будет `C:\ServerProfile\profile\ricon-radio-hardware.json`. Изменения загружаются при следующем запуске сценария с включённым режимом смешанного оборудования.

В примере уже есть шесть отдельных блоков `radios`. Карманные рации — `RICON_Pocket_1` и `RICON_Pocket_2`, рюкзачные — `RICON_Manpack_1` и `RICON_Manpack_2`, автомобильные — `RICON_Vehicle_1` и `RICON_Vehicle_2`. Значение `id` — уникальное имя сущности в World Editor. Для дополнительной рации или машины задайте ей имя в сценарии, скопируйте подходящий блок и поменяйте `id`.

Если нужен профиль по умолчанию для экземпляров одной модели, добавьте отдельный блок с полным именем шаблона в `prefab`. Блок по `id` имеет приоритет над `prefab`. При отсутствии совпадения используются встроенные параметры типа. Частоту и полосу задаёт канал сценария.

`_comment` — поля с пояснениями в обычном JSON. Файл без ошибок применяется целиком. Повтор одного ключа, неполный блок или отрицательный коэффициент шума отклоняют конфигурацию и дают `INVALID_RADIO_HARDWARE_CONFIG` в журнале. При отсутствии файла сервер использует встроенные профили.
